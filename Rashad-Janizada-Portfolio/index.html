About

Both sides of the stack, and the tests in between.

I'm a Computer Science student at Eötvös Loránd University who writes software and then goes looking for the ways it fails.

On the front end I build responsive interfaces in JavaScript and React, at my Frontend Development Internship at CodeSentinel and in my own projects. On the back end I write layered, database-driven Java with JDBC, MySQL and Maven.

As a QA Engineering Intern at Azerconnect Group I did manual testing, API testing, bug reporting and test automation. That work changed how I write code: I lean on object-oriented design, data structures and algorithms, and JUnit tests to keep applications modular, maintainable and reliable.

Three internships taught me to work inside Agile teams on feature development, testing and code quality. I want to contribute across the full software development lifecycle.
