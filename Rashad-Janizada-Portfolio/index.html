About

Building things, understanding how they work.

I'm a final-year Computer Science student at Eötvös Loránd University (ELTE) in Budapest, drawn to the parts of software that most people never see — how a system stays correct under pressure, how a codebase stays readable a year later, how a small design decision saves a hundred future headaches.

My work spans full-stack development: Java backends with layered architecture and JUnit-tested logic, relational data modelling with MySQL and JDBC, and frontend interfaces built with clean, dependency-light JavaScript. Internships at Yelo Bank and CodeSentinel gave me a first real taste of Agile teams, code review culture, and shipping features that other engineers depend on.

Outside of coursework, I keep circling back to the same questions — good architecture, sensible testing, and code a teammate can read without asking me first. I'm currently preparing for graduate software engineering roles and a Master's degree in Germany.
