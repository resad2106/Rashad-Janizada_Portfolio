# Rashad Janizada Portfolio

Single-page personal portfolio: 3D hero built with Three.js, dark and light themes, and a downloadable CV.

- `Rashad-Janizada-Portfolio/index.html` is the whole site (inline CSS and JavaScript, CV and certificates embedded).
- `Rashad-Janizada-Portfolio/Rashad_Janizada_CV.pdf` is a separate copy of the CV.
- `Rashad-Janizada-Portfolio/Rashad_Janizada_IBM_Certificate.pdf` is a separate copy of the IBM certificate.
- `Rashad-Janizada-Portfolio/Rashad_Janizada_Meta_Certificate.pdf` is a separate copy of the Meta certificate.
- `Rashad-Janizada-Portfolio/Rashad_Janizada_CodeSentinel_Certificate.pdf` is a separate copy of the CodeSentinel certificate.
- `netlify.toml` tells Netlify to publish the `Rashad-Janizada-Portfolio` folder.

Open `index.html` in a browser to view it locally.
